# 指定页面布局为「首页」模板（home 布局会渲染 hero 和 features 区域）
layout: home

# —— 顶部主视觉区（Hero）——
hero:
  # 主标题（大字号，显示在页面最上方）
  name: "饱餐后的胡言乱语"
  # 副标题（紧跟主标题下方，字号次之）
  text: ""
  # 标语/描述（hero 底部的灰色小字）
  tagline: ""
  # 说明：原本这里有两个按钮（Markdown Examples / API Examples），
  # 已按用户要求移除，首页不再显示它们。

# 注意：这里故意不写 features 配置。
# 默认首页模板会在 hero 下方渲染 features 三栏卡片，会占掉一大块空间、
# 把下方自定义的横向滑动文章列表（PostCarousel）挤到屏幕外。
# 去掉 features 后，横向文章列表会紧跟 hero 显示。
